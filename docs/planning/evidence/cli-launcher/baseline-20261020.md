## Exact edit map and behavior

1. cli/root.go New's root RunE dispatches to a private launcher-or-help function
   after preserving the existing context check. Only real stdin/stdout terminals,
   auto/human output, non-CI and a usable TERM qualify. --help, explicit json,
   redirects, missing terminals, direct commands and dumb terminals retain static
   noninteractive help/behavior. Never read /dev/tty to circumvent redirection.
2. Keep presentation/settings/catalog ownership in internal/cli. Add private
   launcher view/key/state code there. Reuse p.text, p.paint, displayWidth and
   existing settings read/atomic write. Add fixed core menu translations to the
   existing catalogs for all seven languages; complete English/Korean templates,
   deterministic English fallback for technical secondary-language details.
3. Main menu: usage/examples, language settings, explicit environment diagnosis,
   exit. Full Heliopause Artifact Airlock name stays visible. Arrows move,
   Enter selects, Esc returns one level, q/Ctrl-D exit, Ctrl-C preserves an
   interruption outcome. Help/detail views scroll and return to their parent.
   Display static examples only: never turn menu text into shell/process argv,
   never call install/update/inspect or repair/download just by opening a screen.
4. Usage browser is derived from the actual registered command tree; use current
   help APIs, not historical illustrative pip inspect/review commands. A bounded
   help buffer (no embedding that bypasses Write via ReaderFrom) caps text at
   64KiB. Examples use exact registered command paths/flags and label target,
   project/venv and managed-update prerequisites. Examples remain inert text.
5. Language menu calls writeLanguageSettings, then p.configure, and re-renders.
   Saved auto remains auto. Show saved/effective/source/fallback with existing
   selection meanings. Explicit --lang and HELOX_LANG keep their precedence;
   show an override explanation instead of pretending saved language took effect.
   Invalid/corrupt settings retain existing reset capability; write failure is
   visible and never reported as saved. Do not echo raw OS/path errors.
6. AddDoctor retains direct-command behavior and privately supplies that same
   service to the launcher. Bare-source bootstrap binds a lazy doctorService
   without resolving the release directory or composing a runtime. Only explicit
   menu selection calls Diagnose with parent context and a bounded timeout.
   DefaultRoot resolution happens at that point; unavailable root becomes a
   fixed unavailable check. Other fixed checks use the existing service.
   No background check occurs on startup, settings/help or resize. Direct doctor
   still exits1 when unhealthy. The menu shows per-check OK/UNAVAILABLE and fixed
   details with the same descriptions, remains navigable, and does not claim
   artifact inspection or overall readiness from menu exit0.
7. Unix terminal adapters are build-selected for Linux/Darwin with correct
   ioctl request signatures; other platforms use static fallback. Snapshot full
   input termios, enable noncanonical bounded read, and restore exact original
   termios in a defer. Avoid unsafe/cgo/new process/framework/dependency.
   Poll in short context-aware intervals; no permanently blocked read goroutine
   or global FD nonblocking flag changes. A bounded escape-sequence decoder
   handles split arrows and standalone Esc with a short ambiguity interval.
8. Own alternate-screen/cursor changes with a defer registered before the first
   write. Restore screen/cursor/SGR and termios on normal exit, cancellation, EOF,
   input/output failure and initialization failure; join cleanup errors without
   replacing the primary cause. SIGINT/SIGTERM use existing process cancellation.
   SIGKILL cannot run cleanup and is not promised. Do not change product signals.
9. Read actual stdout geometry and bound frame rows/cells; menu/detail viewports
   keep selection visible, preserve complete content by scrolling, and redraw
   after resize. Avoid last-column autowrap. Handle narrow CJK text using existing
   display-width helpers. Extremely small/unavailable geometry has a documented
   static fallback; NO_COLOR and --color=never suppress SGR colors while retaining
   navigation controls. Reuse existing explicit --color=always precedence.
   New screen lines are fixed catalog/static help or bounded sanitized codes;
   no raw provider/OS output, paths or terminal escape data are replayed.
